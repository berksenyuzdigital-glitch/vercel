# Technical Visualization

Accuracy over decoration. Never hallucinate a mechanical component, architectural structure, internal electronics, dimension, material, assembly sequence, or engineering label that wasn't actually supplied — mark unverified areas as conceptual/illustrative/schematic instead.

## Exploded views

`Exploded View/Diagram/Assembly`, `Exploded Axonometric/Isometric/Perspective`, `Assembly Breakdown`, `Component Breakdown`, `Product Deconstruction`, `Disassembled View`, `Floating Components`, `Layer Stack`, `Layered Exploded View`, `Expanded Assembly`, `Technical Exploded View`.

Preserve when exploding: the true **assembly axis**, **part hierarchy**, **mechanical relationships**, readable spacing, correct component ordering, and visual alignment. Parts never fly apart randomly.

## Cutaway / section

`Cutaway View/Illustration`, `Peel-Away`, `Shell Removed`, `Breakaway Cutaway`, `Selective/Transparent/Ghosted Cutaway`.

Section terminology: `Section View`, `Cross-Section`, `Longitudinal/Transverse Section`, `Full/Half Section`, `Offset/Stepped Section`, `Broken-Out/Revolved/Removed/Aligned Section`, `Partial Section`, `Section Perspective`, `Section Axonometric`, `Clipping Plane`, `Slice View`.

## Transparent / X-ray

`X-Ray View`, `Ghosted View`, `Phantom View`, `Transparent View`, `Semi-Transparent Shell`, `See-Through View`, `Internal Anatomy View`, `Ghosted Exploded View`, `Exploded X-Ray`, `Transparent Cutaway`.

Rule: the outer shell must never hide the internal structure it exists to reveal. If transparency muddies the visual hierarchy, use a ghosted shell instead of full transparency.

## Technical illustration

`Technical/Engineering/Industrial/Scientific Illustration`, `Patent Drawing`, `Blueprint`, `CAD Drawing`, `Line Drawing/Art`, `Hidden-Line View`, `Wireframe View`, `Shaded Wireframe`, `Technical Diagram`, `Schematic`, `Assembly Drawing`, `Detail Drawing`, `General Arrangement Drawing`, `Auxiliary/Detail/Broken/Partial/Local View`.

## Architectural visualization

`Archviz`, `Exterior/Interior Rendering`, `Site Plan`, `Floor Plan` (`3D Floor Plan`), `Isometric/Axonometric Plan`, `Architectural Section`, `Section Perspective`, `Exploded Building Diagram`, `Exploded Axonometric Architecture`, `Cutaway Architecture`, `Massing/Program/Circulation/Zoning/Spatial Diagram`, `Structural/Envelope Diagram`, `Site Analysis/Environmental Diagram`, `Solar Analysis`, `Shadow Study`, `Phasing Diagram`, `Wall Assembly Diagram`, `Layered/Narrative/Analytical/Programmatic/Conceptual Axonometric`.

## Diagram / information visualization

`Diagrammatic View`, `Analytical/Conceptual Diagram`, `Schematic/Process/Flow Diagram`, `System/Layer Diagram`, `Functional/Relationship Diagram`, `Callout Diagram`, `Annotation Layer`, `Label Leader`, `Numbered Components`, `Legend`, `Scale Indicator`.

Never invent labels, component names, or functions that weren't supplied — a diagram that looks authoritative but fabricates its own content is worse than one that's honestly incomplete.
