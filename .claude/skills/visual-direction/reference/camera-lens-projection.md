# Camera, Lens & Projection Vocabulary

## Camera angles / viewpoints

Pick deliberately — ask: which angle makes this subject read strongest? How does it affect perceived scale? Does it leave enough negative space for the website copy? Does it support the brand's character?

`Eye-Level`, `High-Angle`, `Low-Angle`, `Bird's-Eye`, `Worm's-Eye`, `Top-Down`, `Overhead`, `Three-Quarter (3/4)`, `Front`, `Rear`, `Side / Profile`, `Ground-Level`, `Aerial`, `Drone`, `Hero Angle`, `Dutch / Canted Angle`, `Point-of-View (POV)`, `Over-the-Shoulder`.

## Shot scale

`Extreme Close-Up`, `Close-Up`, `Detail Shot`, `Macro Shot`, `Medium Close-Up`, `Medium Shot`, `Full Shot`, `Wide Shot`, `Extreme Wide Shot`, `Establishing Shot`, `Beauty Shot`, `Product Hero Shot`.

## Perspective / projection systems

`Perspective`, `Parallel`, `Orthographic`, `Isometric`, `Axonometric`, `Dimetric`, `Trimetric`, `Oblique` (`Cavalier`, `Cabinet`), `Planometric`, `One/Two/Three-Point Perspective`, `Forced Perspective`, `Fisheye`, `Panoramic`, `Wide-Angle`, `Telephoto Compression`.

**Choice rule:**
- Technical explanation → orthographic / isometric / axonometric.
- Premium product hero → perspective / three-quarter.
- Architecture diagram → axonometric / section perspective.
- Immersive cinematic scene → perspective camera.

## Lens & optics

Focal lengths and their typical use:

| Range | Use |
|---|---|
| 14–24mm | Dramatic architecture, exaggerated spatial depth |
| 28–35mm | Environmental storytelling, interiors |
| 50mm | Natural premium product perspective |
| 70–85mm | Luxury product / portrait-like compression |
| 100mm Macro | Material / product detail |
| 135mm+ | Strong telephoto compression |

Lens types to know: `Ultra-Wide`, `Wide-Angle`, `Normal`, `Telephoto`, `Macro`, `Fisheye`, `Tilt-Shift`, `Anamorphic`, `Prime`, `Zoom`.

Optical terminology: `Focal Length`, `Lens Compression`, `Perspective Distortion`, `Barrel Distortion`, `Depth of Field` (`Shallow` / `Deep Focus`), `Focus Falloff`, `Selective Focus`, `Bokeh`, `Rack Focus`, `Hyperfocal Distance`.

"Cinematic camera" alone is not a spec — always pair **angle + focal length + camera distance + depth of field**.

## Camera movement (video / scroll-driven 3D)

`Pan`, `Tilt`, `Roll`, `Dolly-In/Out`, `Push-In`, `Pull-Out`, `Tracking Shot`, `Truck`, `Pedestal Up/Down`, `Crane Shot`, `Jib Shot`, `Orbit`, `Arc Shot`, `360 Orbit`, `Fly-Through`, `Walkthrough`, `Camera Follow`, `Reveal Move`, `Zoom-In/Out`, `Dolly Zoom` (vertigo effect), `Parallax Camera Move`, `Locked-Off / Static Camera`, `Slow Drift`, `Micro Camera Movement`.

Scroll-specific: `Scroll-Driven Camera`, `Camera Dolly on Scroll`, `Camera Orbit on Scroll`, `Camera Push-In on Scroll`, `Parallax Camera Move`, `Scroll-Scrubbed Camera`, `Depth Transition`, `Spatial Transition`.

**Rule:** camera movement exists to support a narrative/state change, never purely for spectacle. Every scroll segment should map to an actual state change — see `anti-generic-and-examples.md` for a worked scroll-choreography example.
